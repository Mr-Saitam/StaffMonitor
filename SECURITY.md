# Security Policy

## Supported Versions

The following versions of StaffMonitor are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x-beta | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in StaffMonitor, please report it responsibly.

**Do not disclose security vulnerabilities publicly through GitHub Issues.**

Instead, contact the developer directly:

- **GitHub:** [@Mr-Saitam](https://github.com/Mr-Saitam)

When reporting a vulnerability, please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any relevant logs or screenshots.

Please allow reasonable time for the issue to be investigated and addressed before making it public.

## Scope

Security reports may include issues related to:

- Unauthorized access to the dashboard.
- Authentication and access approval.
- Exposure of staff activity or stored data.
- SQL injection or other database vulnerabilities.
- Remote code execution or privilege escalation.
- Improper handling of sensitive information.
